# Basic Jetpack Compose Project

This repository contains my practice project while learning the basic concepts of **Jetpack Compose** for Android development.

##  About the Project

The goal of this project is to understand how to build user interfaces using Jetpack Compose instead of XML layouts.

In this project, I am practicing:

* Composable functions
* Text components
* Buttons
* State management
* Layouts such as Column and Row
* Basic UI structure
* Preview in Android Studio

## 🛠️ Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Material Design

##  What I Am Learning

This project is part of my journey to become a Junior Android Developer.

I am currently learning how Compose works, how to organize simple UI components, and how to create interactive screens using Kotlin.
